# Потік монет

Лендинг сервісу планування особистого бюджету із симулятором заощаджень.
Навчальний проєкт з дисципліни «Технології веб-розробки та дизайну» (ЛР №5–№12).

## Що це

Односторінковий сайт: користувач рухає три повзунки (дохід, витрати, термін) і бачить прогнозовану суму
заощаджень. На сторінці також є відео про планування бюджету, інтерактивна карта та форма зворотного зв'язку.

## Технології

- HTML5 (семантичні теги `header`, `main`, `section`, `article`, `aside`, `footer`)
- Tailwind CSS 3.4 (збирається Tailwind CLI в `assets/css/styles.css`) + невеликий файл `custom-styles.css`
- Vanilla JavaScript (мобільне меню, валідація форми, модальне вікно)
- Плагіни через CDN (ЛР №10): Swiper 11.1.14, Fancybox 5.0.36, Typed.js 2.1.0
- Google Fonts (Inter, Montserrat), іконки як вбудований SVG-спрайт

## Запуск локально

1. Клонувати репозиторій: `git clone <посилання на репозиторій>`
2. Відкрити папку у VS Code: File → Open Folder.
3. Правою кнопкою на `index.html` → Open with Live Server (розширення Live Server).
   Можна й просто відкрити `index.html` у браузері. Потрібен інтернет: шрифти та плагіни підключені через CDN.

## Плагіни (ЛР №10)

| Плагін | Де використано | Налаштування |
|---|---|---|
| Swiper | слайдер «Приклади сценаріїв накопичення» (5 слайдів) | `loop`, автоплей 3,5 с із паузою при наведенні, стрілки, клікабельна пагінація, 1/2/3 слайди на екрані (брейкпоінти 0/768/1024 px) |
| Fancybox | галерея «Як виглядає сервіс» (4 знімки секцій сайту) | група `data-fancybox="service-gallery"`, підписи `data-caption`, ефект fade, зум |
| Typed.js | рядок «Накопичуйте на …» у Hero | 4 фрази, цикл; для скрінрідерів є прихований повний текст |

CSS плагінів підключено в `<head>`, JS із `defer` перед `</body>`, ініціалізація в `assets/js/plugins.js` обгорнута в
`DOMContentLoaded`. Якщо користувач просить менше анімацій (`prefers-reduced-motion`), автоплей і друк вимикаються.

## Симулятор накопичень (ЛР №11)

Інтерактивний віджет на чистому JavaScript. Результат оновлюється одразу при введенні (`input`) або зміні списку й прапорця (`change`).

Формула: щомісячний внесок `s = дохід − витрати`. Без відсотків сума `s × термін`. Зі ставкою `r` % річних, `i = r / 12 / 100`:
складні відсотки `s × ((1 + i)^n − 1) / i`, прості відсотки `s × n + s × i × n × (n − 1) / 2`.

| Поле | Тип | Правило |
|---|---|---|
| Дохід, грн | number | від 1 до 1 000 000, до копійок |
| Витрати, грн | number | від 0 до 1 000 000, до копійок |
| Термін, міс. | number | ціле від 1 до 120 (дробове округлюється з поясненням) |
| Ставка | select | 0, 8, 12 або 15 % (інше значення відхиляється) |
| Капіталізація | checkbox | доступна лише при ненульовій ставці |

Захист від Edge Cases: порожнє поле, нуль, від'ємне, надто велике, `Infinity`, не число, дробове, швидка зміна значень,
підмінений `select`, відсутній елемент DOM, пошкоджене збереження. Дані користувача виводяться лише через `textContent`.

Логіка в `assets/js/savings-calc.js` (без DOM), зв'язок зі сторінкою в `assets/js/widget.js`. Автотести: `node --test tests/savings-calc.test.js`.

## Аудит і CI/CD (ЛР №12)

Збірка CSS: `npm install`, потім `npm run build:css` (результат лежить у `assets/css/styles.css` і закомічений, тож для публікації збірка не потрібна).
Тести: `npm test`.

### Lighthouse (мобільний режим, локальний сервер, медіана трьох запусків)

| Показник | До | Після |
|---|---|---|
| Performance | 64 | 100 |
| Accessibility | 100 | 100 |
| Best Practices | 100 | 100 |
| SEO | 100 | 100 |
| LCP | 6,2 с | 1,6 с |
| FCP | 5,5 с | 1,1 с |
| Передано даних | 725 КіБ | 329 КіБ |
| Запитів | 27 | 22 |

Що змінено: Tailwind CDN-скрипт замінено зібраним CSS (17 КіБ замість 124 КіБ JS); Font Awesome (близько 290 КіБ шрифтів заради 9 іконок)
замінено SVG-спрайтом; CSS Swiper, Fancybox і Google Fonts завантажуються без блокування відображення; hero-зображення отримало
`fetchpriority="high"`. Після оптимізації знайдено й виправлено: невідповідність видимого тексту та `aria-label` у соцмережах,
крапки пагінації слайдера менші за 24 px.

Заміри зроблено на локальному сервері. На Vercel значення можуть відрізнятися, тому для звіту повторіть аудит на опублікованій версії.

### CI/CD

`.github/workflows/deploy.yml` запускається після push у `main`: `npm ci`, тести, збірка CSS із перевіркою, що результат актуальний,
публікація на Vercel. Потрібен секрет `VERCEL_TOKEN` (GitHub: Settings → Secrets and variables → Actions).
`vercel.json` задає кеш для `assets/` і базові заголовки безпеки.
